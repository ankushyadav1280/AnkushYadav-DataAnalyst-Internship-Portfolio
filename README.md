## 📈 Key Project Highlights

| Metric | Result |
|---|---|
| Dataset Records | 1,000 |
| Total Revenue | ₹139,399,439.65 |
| Statistical Test | Welch's T-Test |
| Significance Level | 0.05 |
| P-Value | 0.302339 |
| Cohen's d | 0.065341 |
| Preliminary Decision | Fail to Reject H0 |

The hypothesis test provides insufficient evidence of a statistically significant difference in average order value between male and female customers. Repeated customer orders and identifier inconsistencies limit the statistical interpretation.
